## Defect and reviewed correction

Root reported that the first authorized live Codex attempt changed the prepared `sum.ts` during the denial phase without a host permission request. The adapter had mapped host workspace-write and ask to native `workspaceWrite` and `on-request`. Native patch safety can automatically approve writable targets under those settings. The host's permission to review individual patches had become broad native write authority.

The corrected adapter requests `read-only` for thread creation and exact-ID resume, and `readOnly` for every turn, with network disabled. Ask maps to `untrusted`; deny maps to `never`. Adoption rejects a different approval policy or reviewer, writable sandbox, network access, or unexpected sandbox fields. Every dispatch revalidates native account/configuration evidence. A host workspace-write policy is still necessary for a reviewed patch, but never grants a writable native workspace. [Pinned patch safety](https://github.com/openai/codex/blob/rust-v0.153.4/codex-rs/core/src/safety.rs)

An observed patch may receive only a one-time native `accept`, guarded by current protected host review at the final reply write. Grant roots, session approval, commands and permission-profile expansion remain denied. Native approval caching records approval for the session; plain approval does not create that cache entry. [Pinned approval handling](https://github.com/openai/codex/blob/rust-v0.153.4/codex-rs/core/src/tools/sandboxing.rs)

Saved native exec-policy allow rules can bypass a requested sandbox. The correction therefore forces `features.shell_tool=false` and requires its exact effective configuration readback. The pinned registry checks this gate before registering both command execution and stdin; it covers unified execution and the one-shot fallback. Code mode gathers its nested tools from that registry and does not restore removed shell handlers. Native shell reads and test commands are consequently unavailable; callers supply selected file context and run validation outside the native turn. [Pinned execution policy](https://github.com/openai/codex/blob/rust-v0.153.4/codex-rs/core/src/exec_policy.rs), [pinned tool registration](https://github.com/openai/codex/blob/rust-v0.153.4/codex-rs/core/src/tools/spec_plan.rs)
