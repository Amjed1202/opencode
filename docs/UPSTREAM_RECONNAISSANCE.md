# OpenCode v1.18.29 source reconnaissance

Inspected local checkout `outputs/harness` pinned at `16747470f976aca3d362ad730bcd3fe82ecc2c9a`. This report is source evidence and proposed reuse decisions; it does not claim the unimplemented Harness UI, adapters, remote daemon or billing safeguards already work. Source citations use immutable commit URLs. No upstream code was modified by this reconnaissance.

## Decisions with architectural impact

1. **Electron is the active desktop stack.** `packages/desktop` runs `electron-vite`, uses Electron 42.3.3 / electron-builder / electron-updater and imports `@opencode-ai/app`. There is no `packages/desktop-electron` at this pin. Tauri CORS aliases, Docker recipes and migration remnants do not make Tauri the current stack. [packages/desktop/package.json:12](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/desktop/package.json#L12)
2. **Upstream has already split Schema / Core / Protocol / Server / Client / SDK Next.** Respect its direction: Schema to Core/Protocol, Core+Protocol to Server; Client runtime only Schema/Protocol; SDK Next composes client/core/server. New product packages must be separately named (for example `packages/harness-protocol` / `@harness/protocol`), with no rename of `packages/protocol`. [AGENTS.md:1](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/AGENTS.md#L1) [packages/schema/AGENTS.md:1](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/schema/AGENTS.md#L1)
3. **This stable release contains a transitional runtime.** The shipping server merges legacy root/instance routes and current Server routes. App and session-ui deliberately use a vendored `opencode-ai-client-1.17.13-v2.tgz`, while also depending on legacy SDK and Core. “V2” is not one coherent compatibility promise across all packages. [packages/opencode/src/server/routes/instance/httpapi/server.ts:271](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/opencode/src/server/routes/instance/httpapi/server.ts#L271) [packages/opencode/src/server/routes/instance/httpapi/api.ts:48](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/opencode/src/server/routes/instance/httpapi/api.ts#L48) [packages/app/package.json:57](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/app/package.json#L57) [packages/session-ui/package.json:41](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/session-ui/package.json#L41)
4. **Current API is not full legacy parity.** Current `SessionV2` admits/resumes/interrupts and switches agent/model, but `shell`, `skill`, `compact`, `wait` explicitly return `OperationUnavailableError`. The runner has automatic compaction behavior; that does not make the explicit compact API available. MCP runtime remains in the legacy opencode package. Keep a capability/version matrix and pick one tested OpenCode transport surface per adapter connection. [packages/core/src/session.ts:387](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/session.ts#L387) [packages/opencode/src/mcp/index.ts:1](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/opencode/src/mcp/index.ts#L1)
5. **OpenCode is an independent runtime, not the universal coordinator.** AgentV2 is a location-scoped map of OpenCode agent configurations. Core native LLM transport is a provider-turn abstraction. Neither is an adapter for native Claude Code/Codex App Server. Upstream OpenAI integration contains its own OAuth implementation and AI SDK model selection; it must not be relabeled native Codex authentication. [packages/core/src/agent.ts:17](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/agent.ts#L17) [packages/core/src/plugin/provider/openai.ts:14](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/plugin/provider/openai.ts#L14) [packages/llm/AGENTS.md:1](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/llm/AGENTS.md#L1)
6. **Data isolation is mandatory before importing/starting this fork.** `Global` hardcodes app directory `opencode` and creates directories at import time. Core applies its own migrations automatically. A migration at this release deletes current session projections, event log/sequences, pending inputs, context epochs and workspace rows. A fork must never point exploratory runs at the user's existing OpenCode data. Use isolated XDG data/config/state/cache plus `OPENCODE_DB` before module import; separate Harness database/migrations from upstream database. [packages/core/src/global.ts:10](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/global.ts#L10) [packages/core/src/database/database.ts:22](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/database/database.ts#L22) [packages/core/src/database/migration/20260622170816_reset_v2_session_state.ts:1](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/database/migration/20260622170816_reset_v2_session_state.ts#L1)
7. **Do not reuse upstream secret persistence or environment inheritance unchanged.** Credentials are JSON in SQLite; sidecar and PTY code inherit parent environment. Native subscription launch must have provider-specific allowlisted environment construction and official native runtime authentication; API credential variables must not be accidentally forwarded. [packages/core/src/credential/sql.ts:5](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/credential/sql.ts#L5) [packages/desktop/src/main/server.ts:215](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/desktop/src/main/server.ts#L215) [packages/core/src/pty.ts:170](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/pty.ts#L170)
8. **Product updater, telemetry and identities need explicit separation before distribution.** Production/beta update config points at anomalyco repositories; Windows currently disables update signature verification and updater allows downgrade. Source-stage work should leave upstream intact and keep new product updater disabled until product identity, signing and feed policy exist. ## Runtime and subsystem source trace

### Native OpenCode session and execution

**WRAP** native session lifecycle and streaming. [packages/core/src/session.ts:123](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/session.ts#L123) defines create/get/list/messages/context/events/history/prompt/resume/interrupt and the unsupported operations. Session creation retains legacy event projection for compatibility. `prompt` records exactly one durable admission, checks exact retry equivalence (session + message ID + prompt + delivery), and sends advisory wake unless `resume:false`; conflicting ID reuse errors. Default delivery is steer, distinct from queue. [packages/core/src/session.ts:360](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/session.ts#L360)

**KEEP** serialized native execution semantics. `SessionExecutionLocal` is process-global, keyed by session ID, resolves location at drain start, and delegates to the location-scoped runner. `SessionRunCoordinator` joins explicit resumes, coalesces wakeups and interrupts active process-local ownership. Different sessions can drain concurrently; this is not permission for multiple writers in the same workspace. [packages/core/src/session/execution/local.ts:11](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/session/execution/local.ts#L11) [packages/core/src/session/run-coordinator.ts:24](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/session/run-coordinator.ts#L24)

**KEEP** model-turn/tool execution inside OpenCode. Runner translates projected history, issues explicit `llm.stream(request)` per provider turn, records local tool invocation, awaits settlements and reloads history before continuation. Do not build a second inner loop around Claude/Codex or call legacy `SessionPrompt.loop` from the universal coordinator. Replays of history are not automatic permission to retry provider work after crash. [packages/core/src/session/runner/llm.ts:64](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/session/runner/llm.ts#L64) [packages/core/src/session/runner/llm.ts:239](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/core/src/session/runner/llm.ts#L239) [AGENTS.md:151](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/AGENTS.md#L151)

Keep native session IDs as opaque adapter bindings under a separate application session ID. [packages/opencode/src/session/prompt.ts:1](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/opencode/src/session/prompt.ts#L1) [packages/sdk/js/package.json:12](https://github.com/anomalyco/opencode/blob/16747470f976aca3d362ad730bcd3fe82ecc2c9a/packages/sdk/js/package.json#L12)

## Refactor and integration hazards to carry into the plan

1. Separate application session IDs, native runtime session IDs, task IDs, process/drain lifetimes and event cursors. Session identity is not a provider turn, and opaque native IDs should never become a global namespace.
2. Upstream has both current and legacy contracts, bridge events and schemas. Limit OpenCode mapping to adapter files and version-specific contract fixtures; no universal event alias to OpenCode Part schema.
3. Whole-package imports may trigger global filesystem creation/provider refresh/observability setup before launch guards. Resolve product environment/data isolation before dynamic import or process start.
4. Current location scoping is useful but not a remote security model. Explicit workspace identity is reserved for evolving placement semantics; use a product execution target model rather than overloading native WorkspaceV2.
5. Upstream provider “OAuth”, LLM “native” transport, “control-plane” and SDK “v2” names are easily confused with requested native runtime adapters. Keep terminology and actual backing implementation explicit in docs and types.
6. Single-writer lease, reviewer read-only enforcement, cross-runtime collaboration decisions and budgets are product responsibilities absent from native worktree mechanics. Design these types now; implementation later.
7. Product account/billing preflight cannot trust a selected model name or mere API key absence. Native authenticated account status, provider policy and launch environment determine evidence; unknown remains unknown and automatic PAYG fallback defaults off.
8. For source-stage scaffolding, additive types/interfaces/TODOs are the safe divergence: no desktop rebrand implementation, SDK installation, live runtime login, process spawning, paid requests, database opening, migration, secret handling or remote server should be needed.
