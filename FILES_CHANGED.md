# Changed files

The fork now contains architecture, three Harness packages and the local host/Codex implementation with encrypted interaction review, fixed-choice input, durable decisions and native history inspection. The desktop flow remains unimplemented. See [M1A_IMPLEMENTATION.md](M1A_IMPLEMENTATION.md) for supported behavior and remaining gates.

Compared with pinned OpenCode v1.18.29, only two preexisting tracked files change: SECURITY.md gains the Harness policy while preserving the original, and bun.lock gains the three local workspace records and two existing-catalog Bun type references. No upstream functional source, root workspace/build manifest or MIT notice changes. Native generated types retain separate OpenAI Apache-2.0 license attribution.

All other files below are additions relative to that pinned release. Validation artifacts are reviewable evidence; runtime tools, caches and scratch state remain outside this repository.
